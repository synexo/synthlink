What's new

  • PETSCII support (40 column) with WORD BBS as a featured board. This is the second alternate encoding (after Amiga Topaz for ABSiNTHE BBS). A handful of BBSs are configured for them and I'm seeking more. PETSCII (80 column) then ATASCII are next.
  • Bell 103 (300 baud) moved off V.8 for a more authentic early-era modem handshake.
  • V.90 handshakes are more complete with real Phase 2 & Phase 3 + Phase 4 parameter exchange.
  • V.34 symbol rate is now exact correcting a rounded value that supported 33.6kbps speeds.
  • V.32 / V.32bis improved to run the full four-way startup.
  • Status line detail increased showing each handshake signal.

Over 1,000 dials our first week!
